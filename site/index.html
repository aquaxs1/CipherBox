CipherBox ist eine Desktop-App, die lokale Dateien mit AES (Fernet) und PBKDF2-HMAC-SHA256 verschlüsselt. Ein Master-Passwort, keine Cloud, kein Konto.

Installieren Quellcode

Install

Benötigt Python 3.10 oder neuer (Windows, macOS, Linux).

git clone https://github.com/aquaxs1/CipherBox---File-Encrypter.git
cd CipherBox---File-Encrypter
pip install -r requirements.txt

Installiert customtkinter und cryptography.

Wie man es benutzt

python main.py
  1. Erster Start: CipherBox generiert ein 32-Zeichen Master-Passwort. Sicher abspeichern — ohne dieses Passwort gibt es keine Wiederherstellung.
  2. Verschlüsseln: Tab „Encrypt Files“ → Dateien hinzufügen → optional Dateinamen verschlüsseln → starten. Originale werden sicher überschrieben und gelöscht, übrig bleiben .cipherbox-Dateien.
  3. Entschlüsseln: Tab „Decrypt Files“ → .cipherbox-Dateien wählen → Master-Passwort eingeben. Originalnamen und -inhalte werden wiederhergestellt.

Für Skripte lassen sich crypto_utils.CryptoManager und config_manager.ConfigManager auch direkt importieren.

Was es kann

Starke Verschlüsselung

Fernet (AES-128-CBC + HMAC-SHA256) mit authentifizierter Integritätsprüfung.

Robuste Key-Ableitung

PBKDF2-HMAC-SHA256 mit 480.000 Iterationen und 32-Byte-Salt (OWASP 2024).

Dateinamen verstecken

Optional werden Dateinamen durch zufällige UUIDs ersetzt und im Container gespeichert.

Sicheres Löschen

Originale werden vor dem Entfernen 3× überschrieben und mit Nullen gefüllt.

Kein Passwort-Speicher

Nur der Salt landet in ~/.cipherbox/config.json (Rechte 0600) — nie das Passwort.

Stapelverarbeitung

Mehrere Dateien auf einmal, moderne GUI, funktioniert auch mit Multi-GB-Dateien.
